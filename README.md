# Obsidian Protocol

Obsidian Protocol is a single-player tactical horror FPS developed with Unreal Engine 5 and C++.

## Core Features

- First-person shooter gameplay
- Mission-based level design
- Human enemy AI
- Anomalous entity AI
- Tactical combat
- Horror-inspired environments
- Weapon and damage systems
- Objective and mission systems

## Tech Stack

- Unreal Engine 5
- C++
- Blueprints
- Git LFS

## Current Status

Early development / prototype stage.
